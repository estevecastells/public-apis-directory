# Contributing

Thanks for helping make this list better! This repo grows through community contributions — please follow these guidelines to keep it clean and useful.

## Adding a new API

1. Fork the repo and create a new branch.
2. Add your entry to the correct category table in `README.md`, in alphabetical order, using this format:

   ```
   | [API Name](https://link-to-docs) | Short one-line description | Auth type | Yes/No | Yes/No/Unknown |
   ```

3. If your API doesn't fit an existing category, propose a new one in your PR description.
4. Confirm the API is:
   - Publicly accessible (a working docs link)
   - Not deprecated or shut down
   - Free to use at some tier (a paid-only API should be clearly noted)
5. Submit a pull request with a clear title, e.g. `Add: OpenSky Network to Transportation`.

## Reporting a broken link or outdated info

Open an issue with the API name, category, and what's wrong (dead link, wrong auth type, etc.), or submit a PR fixing it directly.

## Style rules

- Keep descriptions to one line.
- Use sentence case, no trailing punctuation in the description column.
- Don't advertise your own product unless it's a genuinely free, publicly documented API.
- No affiliate links.

## Code of Conduct

Be respectful. Constructive feedback only. Spam PRs (irrelevant links, self-promotion with no real API) will be closed.
